# Security Policy

## Supported versions

QuadRix is early port software. Only the `main` branch is supported.

## Reporting a vulnerability

Open a private security advisory on GitHub:
`https://github.com/DeoMatiz/QuadRix/security/advisories/new`

Do **not** open a public issue for security problems.

## Scope

QuadRix does not process payments, authentication, or network data yet.
When it does, this file will be updated.
